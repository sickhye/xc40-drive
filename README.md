# XC40 ドライブ 🚙

パパの Volvo XC40（T4 AWD R-Design）の写真から生まれた、小さなドライブゲームです。

▶ **あそぶ**: https://sickhye.github.io/xc40-drive/

## あそびかた

- コインを 7つ、できるだけ はやく あつめよう！
- パソコン: 矢印キー / WASD で運転、R でリセット
- タブレット・スマホ: 画面に出るボタンで運転できます
- ゴールすると記録が自動で保存されます（ランキングは遊んだ端末の中だけに残ります）
- 言葉は画面のボタンで 日本語 / 한국어 を切り替えられます

## クレジット

- ゲーム制作: **Hotoke**（Muse）— 実車の写真をピクセルアートにして、ゲームまで作りました
- 企画・テスト走行: 대장님 & 아들

## 技術メモ

- 単一の HTML ファイルだけで動きます（ビルド不要）— Canvas + WebAudio
- 車の絵は実車の写真をもとに作ったピクセルアートです
